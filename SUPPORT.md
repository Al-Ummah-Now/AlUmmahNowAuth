# Support

| You want to | Go to |
|---|---|
| Report a security problem | [Private vulnerability reporting](https://github.com/Al-Ummah-Now/AlUmmahNowAuth/security/advisories/new) ([SECURITY.md](SECURITY.md)). Never a public issue |
| Get help signing in or with your account | [Contact form](https://videos.alummahnow.net/contact) |
| Report a bug or ask for a feature | [New issue](https://github.com/Al-Ummah-Now/AlUmmahNowAuth/issues/new/choose) |
| Report a problem in the OpenAuth fork | [An issue here](https://github.com/Al-Ummah-Now/AlUmmahNowAuth/issues/new/choose): the fork's own issues are off |
| Understand or change the code | [CONTRIBUTING.md](CONTRIBUTING.md) and the [wiki](https://github.com/Al-Ummah-Now/AlUmmahNowWiki/blob/main/repos/AlUmmahNowAuth.md) |

Only the latest release is supported. Every merge to `main` is released.
